# Автоподача показаний счётчиков на pesc.ru

Программа сама заходит на сайт [ikus.pesc.ru](https://ikus.pesc.ru) и каждый месяц подаёт показания счётчиков — без вашего участия.

## Что умеет

- Показывает текущие показания всех ваших счётчиков на одной странице
- Позволяет вручную ввести и отправить показания
- Автоматически подаёт показания каждый месяц с 15 по 21 число (в рабочие дни)
- Ведёт журнал всех автоматических подач — когда было, успешно или нет

## Что нужно для установки

- Компьютер или сервер с Linux, который работает круглосуточно
- Python 3.10 или новее
- Учётная запись на [ikus.pesc.ru](https://ikus.pesc.ru)

## Установка

**1. Скачайте программу**

```bash
git clone https://github.com/hram/pesc.git
cd pesc
```

**2. Установите зависимости**

```bash
pip install -e ".[dev]"
```

**3. Создайте файл настроек**

```bash
cp .env.example .env
```

Откройте файл `.env` в любом текстовом редакторе и заполните:

```
PESC_LOGIN=79001234567        # ваш номер телефона (логин на сайте)
PESC_PASSWORD=ваш_пароль
PESC_AUTH_VERIFICATION=...    # см. шаг 4
```

**4. Получите значение PESC_AUTH_VERIFICATION**

Это специальный код, который сайт pesc.ru требует при входе. Получить его можно один раз через браузер:

1. Откройте [ikus.pesc.ru](https://ikus.pesc.ru) в браузере
2. Нажмите F12 → вкладка **Network** (Сеть)
3. Войдите в свой аккаунт
4. В списке запросов найдите запрос к `/api/v8/users/auth`
5. Откройте его → вкладка **Request Headers**
6. Скопируйте значение заголовка `Auth-Verification`
7. Вставьте его в `.env`:
   ```
   PESC_AUTH_VERIFICATION=скопированное_значение
   ```

## Запуск

```bash
uvicorn portal.main:app --port 8003
```

Откройте браузер и перейдите по адресу: **http://localhost:8003**

## Как пользоваться

**Главная страница** показывает все ваши счётчики. Для каждого лицевого счёта можно:
- Посмотреть текущие показания
- Ввести новые показания вручную и нажать **Подать показания**
- Включить тумблер **Подавать автоматически** — тогда программа будет сама подавать показания каждый месяц

**Журнал** (ссылка в правом верхнем углу) показывает историю всех автоматических подач.

## Автоматическая подача

Когда включена опция **Подавать автоматически**, программа каждый день в 12:00 (по московскому времени) проверяет: если сегодня с 15 по 21 число и рабочий день — подаёт показания.

Изменить время проверки можно в файле `.env`:

```
SCHEDULER_HOUR=10    # час (по московскому времени)
SCHEDULER_MINUTE=30  # минуты
```

> **Важно:** компьютер должен быть включён в момент автоподачи.

## Если у вас двухфакторная аутентификация (2FA)

Если при входе на pesc.ru сайт просит код из приложения-аутентификатора (Google Authenticator и подобные), добавьте в `.env`:

```
PESC_TOTP_SECRET=ваш_секретный_ключ
```

Секретный ключ — это строка букв и цифр, которую показывает сайт при настройке 2FA (обычно под QR-кодом).

## Если вы находитесь за пределами России

Сайт pesc.ru блокирует доступ с иностранных IP-адресов. Если программа работает на сервере вне России, укажите адрес прокси-сервера с российским IP:

```
PESC_PROXY_URL=http://адрес_прокси:порт
```
